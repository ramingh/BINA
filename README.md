# Bina — سیستم حسابداری لوکال مبتنی بر IndexedDB

پروژه وب‌اپلیکیشن حسابداری چندشرکتی با ذخیره‌سازی محلی در IndexedDB مرورگر.

## ساختار پروژه (در حال استانداردسازی)

```
Bina/
├── docs/                 ← مستندات کامل پروژه
├── admin/                ← مدیریت بانک و همگام‌سازی (به‌زودی)
├── app/                  ← برنامه اصلی (به‌زودی استاندارد می‌شود)
├── demos/
├── tests/
└── legacy/               ← فایل‌های قدیمی
```

برای جزئیات کامل ساختار به فایل زیر مراجعه کنید:

➡️ [docs/STRUCTURE.md](docs/STRUCTURE.md)

برای ادامه کار با AI یا برنامه‌نویس جدید:

➡️ [docs/PROJECT_CONTEXT.md](docs/PROJECT_CONTEXT.md)

## وضعیت فعلی

مرحله استانداردسازی ساختار فایل‌ها و فولدرها در حال انجام است.
