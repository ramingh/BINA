# راهنمای ترمیم سرعت گرید

## مشکل
گرید از ۱ ثانیه → ۵+ ثانیه کند شده بود.

## علت
مترجم (`Dic_sek.Js`) روی هر سلول گرید اجرا می‌شد (۴۰۰۰+ سلول برای ۵۰۰ ردیف).

## راه‌حل — فقط یک فایل را جایگزین کن

### قدم ۱: فایل اصلاح‌شده را دانلود کن

فایل زیر را از پوشه‌ی download بردار:

```
download/FINAL/app/bina/bina-query-view.js
```

### قدم ۲: در پروژه‌ی GitHub خودت این فایل را جایگزین کن

این فایل در مخزن تو در این مسیر است:

```
FINAL/app/bina/bina-query-view.js
```

یعنی فایل قدیمی را پاک کن و فایل جدید را با همین نام و مسیر بگذار.

### قدم ۳: تست کن

1. صفحه را در مرورگر باز کن (hard refresh: Ctrl+Shift+R)
2. یک شرکت و سال انتخاب کن
3. گرید باید در **~۱ ثانیه** باز شود (نه ۵ ثانیه)

---

## چه تغییراتی دادم؟

فقط **۲ خط** به فایل اضافه کردم (با علامت `FIX APPLIED` در کد مشخص شده):

```js
// تغییر ۱: noTranslateBody فعال شد
this.gridOptions = Object.assign(
  { noTranslateBody: true, pageSize: 500 },
  this.desc.gridOptions || {}
);

// تغییر ۲: translate="no" روی کانتینر گرید
const __gridContainer = this.root.querySelector('.bqv-grid');
if (__gridContainer) __gridContainer.setAttribute('translate', 'no');
```

این تغییرات باعث می‌شوند مترجم روی **بدنه‌ی گرید** اجرا نشود (فقط عنوان ستون‌ها ترجمه می‌شود).

---

## اگر بعد از جایگزینی هنوز کند بود

1. **Cache مرورگر را پاک کن** (Ctrl+Shift+R یا Ctrl+F5)
2. **DevTools → Network → Disable cache** را فعال کن
3. **Console را باز کن** و ببین آیا خطایی هست
4. اگر `bina-grid.js00` در همان پوشه هست، **پاکش کن** (فایل backup است)

---

## فایل‌های دیگر که پاک کنی بهتر است

این فایل‌ها تکراری هستند و فقط فضای اشغال می‌کنند:

```
FINAL/app/bina/bina-grid.js00   ← فایل backup (۹۳ KB) — پاک کن
```

بقیه‌ی پاک‌سازی‌ها در فایل `DUPLICATES_LIST.md` توضیح داده شده.
