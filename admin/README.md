# Admin — مدیریت بانک لوکال و همگام‌سازی
این بخش مسئول دریافت داده از SQL Server، ساخت و مدیریت IndexedDB و موتور SQL مدیریتی است.
محتوای اصلی از پوشه قدیمی `BINA_admin` به اینجا منتقل می‌شود.
## ساختار فعلی
- `manager/` → مدیریت دیتابیس و همگام‌سازی
- `sql/` → موتور SQL
- `tests/` → تست‌ها
برای جزئیات کامل به فایل `README_FA.md` مراجعه کنید.
