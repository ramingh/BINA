# ساختار استاندارد پروژه Bina

این فایل توضیح ساختار جدید و استاندارد پروژه است.

## ساختار نهایی مورد نظر

```
Bina/
├── docs/                          ← تمام مستندات
│   ├── PROJECT_CONTEXT.md
│   ├── Cloud_README.md
│   ├── STRUCTURE.md               (این فایل)
│   └── ...
├── admin/                         ← بخش مدیریت بانک و همگام‌سازی (قبلاً BINA_admin)
│   ├── manager/
│   ├── sql/
│   └── tests/
├── app/                           ← برنامه اصلی
│   ├── core/                      ← موتورها (BinaLocalSql و ...)
│   ├── components/                ← کامپوننت‌های UI (Grid, QueryView, Tabs و ...)
│   ├── pages/                     ← صفحات تب‌ها
│   ├── assets/                    ← فونت، css، تصاویر
│   └── shell/                     ← side_bar, app.js, مترجم و ...
├── demos/                         ← صفحات آزمایشی
├── tests/                         ← تست‌ها
└── legacy/                        ← فایل‌های قدیمی و بک‌آپ
```

## وضعیت فعلی (پس از مرحله ۱)

- فولدر `docs/` ساخته شد و مستندات اصلی به آن منتقل شدند.
- ساختار قدیمی هنوز وجود دارد تا چیزی خراب نشود.
- مراحل بعدی: جابجایی تدریجی فایل‌ها به ساختار جدید.

## قوانین

- هیچ فایل کاری را بدون تأیید حذف نمی‌کنیم.
- تغییرات به صورت سازگار با عقب انجام می‌شود.
- اول الگوریتم، بعد کد.
