# ساختار استاندارد پروژه Bina
این فایل توضیح ساختار جدید و استاندارد پروژه است.
## ساختار نهایی مورد نظر
```
Bina/
├── docs/                          ← تمام مستندات
│   ├── PROJECT_CONTEXT.md
│   ├── Cloud_README.md
│   ├── STRUCTURE.md               (این فایل)
│   └── ...
├── admin/                         ← بخش مدیریت بانک و همگام‌سازی (قبلاً BINA_admin)
│   ├── manager/
│   ├── sql/
│   └── tests/
├── app/                           ← برنامه اصلی
│   ├── core/                      ← موتورها (BinaLocalSql و ...)
│   ├── components/                ← کامپوننت‌های UI (Grid, QueryView, Tabs و ...)
│   ├── pages/                     ← صفحات تب‌ها
│   ├── assets/                    ← فونت، css، تصاویر
│   └── shell/                     ← side_bar, app.js, مترجم و ...
├── demos/                         ← صفحات آزمایشی
├── tests/                         ← تست‌ها
└── legacy/                        ← فایل‌های قدیمی و بک‌آپ
```
## وضعیت فعلی
- `docs/` ساخته و مستندات منتقل شد.
- اسکلت `admin/`، `app/` (با زیرپوشه‌ها) و `legacy/` ساخته شد.
- پوشه‌های قدیمی (`BINA_admin`, `Cloud`, `Cloud_Bak` و ...) هنوز وجود دارند تا جابجایی تدریجی و ایمن انجام شود.
## مراحل بعدی
1. انتقال محتوای `BINA_admin` به `admin/`
2. انتقال و مرتب‌سازی محتوای `Cloud/app` به ساختار جدید `app/`
3. انتقال فایل‌های قدیمی به `legacy/`
4. به‌روزرسانی مسیرها در کدها
## قوانین
- هیچ فایل کاری را بدون تأیید حذف نمی‌کنیم.
- تغییرات به صورت سازگار با عقب انجام می‌شود.
- اول الگوریتم، بعد کد.
