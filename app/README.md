# App — برنامه اصلی Bina

## ساختار داخلی

```
app/
├── core/           ← موتورها (BinaLocalSql و ...)
├── components/     ← کامپوننت‌های UI (Grid, QueryView, Tabs و ...)
├── pages/          ← صفحات تب‌ها
├── assets/         ← فونت، CSS، تصاویر
└── shell/          ← side_bar.html، app.js، مترجم و ...
```

این ساختار در حال تکمیل است.
