# Legacy — فایل‌ها و پوشه‌های قدیمی
اینجا فایل‌ها و پوشه‌هایی قرار می‌گیرند که دیگر استفاده اصلی ندارند ولی برای مرجع یا بازیابی نگه داشته می‌شوند.
## محتویات فعلی (در حال انتقال)
- `Cloud_Bak/` → نسخه پشتیبان قدیمی Cloud
- `bina_db-v01.js` و `bina_db-v010.js` → نسخه‌های قدیمی موتور دیتابیس
- سایر فایل‌های آزمایشی ریشه
**توجه:** فعلاً فایل‌های اصلی هنوز در مسیر قدیمی خود هستند. جابجایی فیزیکی کامل به تدریج انجام می‌شود تا چیزی خراب نشود.
